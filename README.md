# Vela

A receipt desk. Scan a slip, confirm the total, and count only the lines that are yours.

Shared meals stay on the bill. Mark a colleague’s dish **Not mine** and the month, drawers, and chart use your share, including a matching share of tax and service.

Slips stay in this browser. Nothing is filed until you say so.

## What it does

- Month desk with category bars and drawers (Personal, Work, Tax packet, Trip)
- Scan or upload a slip, then confirm merchant, tax, service, and lines
- Review queue for a faint read
- Merchant memory for the next visit
- Search, drawer filter, and CSV export
- Duplicate warning on the same merchant, date, and total

## Run

```bash
npm install
npm run dev
```
